Math Game 🎮➗

A simple console-based Math Game built using C++.
The game generates random math questions with different difficulty levels and operation types.

📌 Features
Multiple difficulty levels:
Easy
Medium
Hard
Mix
Multiple operation types:
Addition
Subtraction
Multiplication
Division
Mix
Random question generation
Tracks:
Correct answers
Wrong answers
Final result (Pass / Fail)
Console color feedback:
Green → Correct answer
Red → Wrong answer
Play again system
🛠️ Technologies Used
C++
Standard Library:
<iostream>
<ctime>
<cstdlib>
▶️ How to Run
Compile using g++
g++ main.cpp -o MathGame
Run
./MathGame

On Windows:

MathGame.exe
🎯 Game Flow
Enter number of questions
Choose difficulty level
Choose operation type
Solve the generated questions
View final results
Choose whether to play again
